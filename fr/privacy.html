Ce site

Ce site ne dépose aucun cookie. Pour compter les visites, il utilise Google Analytics 4 de Google Ireland Limited, sans cookies : le consentement au stockage des données d’analyse reste refusé, Google ne stocke donc rien sur votre appareil. À chaque page vue, votre navigateur envoie à Google la page, la page de provenance, l’heure, la langue, la taille de l’écran et votre adresse IP. Google utilise l’adresse IP pour déterminer le pays et ne la conserve pas. Google peut traiter ces données aux États-Unis ; Google est certifié selon le EU-U.S. Data Privacy Framework. La base légale est notre intérêt légitime à savoir comment le site est utilisé (art. 6, par. 1, point f, RGPD). Un bloqueur de contenu dans votre navigateur empêche ces signaux. Les détails figurent dans la politique de confidentialité de Google.

C’est le seul script provenant d’un autre serveur. Le site ne charge aucune police depuis d’autres serveurs.

Le site est hébergé sur GitHub Pages par GitHub, Inc. Pour fournir les pages, GitHub traite des données techniques comme votre adresse IP et l’heure de la requête. Les détails figurent dans la déclaration de confidentialité de GitHub.

Votre choix de langue et d’appareil est conservé uniquement dans votre navigateur. Il ne nous est jamais envoyé.

L’app

  • Pas de compte, pas de serveur à nous. cardXchange conserve vos données sur vos appareils et dans votre iCloud privé. Apple les stocke ; nous n’y avons pas accès.
  • Contacts Apple. cardXchange lit votre carnet d’adresses pour afficher vos personnes. Il n’écrit que ce que vous demandez : un lien vers la personne, des relations, les mises à jour acceptées et, sur Mac si vous l’activez, un court historique dans la note. Le texte de vos notes ne quitte jamais l’appareil.
  • Captures d’écran, cartes de visite et photos sont lues sur l’appareil, avec les frameworks d’Apple sur l’appareil.
  • Carte. Pour afficher les adresses sur la carte, la rue, le code postal, la ville et le pays de chaque adresse sont envoyés au service de géocodage d’Apple. Votre position est affichée sur la carte, mais elle n’est ni enregistrée ni envoyée.
  • Échange de cartes. Quand vous montrez un code de carte, les champs que vous avez choisis pour votre carte sont partagés, par iCloud, avec la seule personne qui scanne le code. Cette personne reçoit aussi chaque modification ultérieure de votre carte. Jusqu’à ce que la personne l’accepte, ou jusqu’à la fin du code après 24 heures, une copie de la carte se trouve dans la partie publique du stockage iCloud de cardXchange, pas dans votre iCloud privé. Toute personne qui a le code peut lire cette copie pendant ce temps. Votre app la supprime après l’acceptation ou après la fin du code, à sa prochaine ouverture.
